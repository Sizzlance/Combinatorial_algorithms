# Combinatorial & Graph Algorithms
Репозиторий содержит реализации классических алгоритмов на графах, выполненные в рамках университетского курса по комбинаторным алгоритмам. 

Все решения реализованы на Python с использованием стандартных структур данных.

## Содержание

1. Поиск циклов в графе
2. Минимальное остовное дерево
3. Компоненты связности
4. Максимальный поток
5. Кратчайшие пути в ориентированном ациклическом графе
6. Динамическая связность
7. Решение задач с Тимуса
